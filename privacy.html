사용 범위

  • 이 앱은 소유자 본인만 사용하는 개인 자동화 도구입니다.
  • Google 사용자 데이터 중 gmail.insert 권한만 요청하며, 소유자 본인의 Gmail 편지함에 메일을 추가하는 데에만 사용합니다.
  • Gmail 메일을 읽거나, 발송하거나, 삭제하지 않습니다.
  • 수집한 데이터를 제3자에게 제공·판매·공유하지 않으며, 광고에 사용하지 않습니다.
  • 인증 토큰은 소유자 본인 기기의 보안 저장소(macOS 키체인)에만 보관합니다.

Scope

  • This app is a personal automation tool used only by its owner.
  • It requests only the gmail.insert scope and uses it solely to add messages to the owner's own Gmail mailbox.
  • It does not read, send, or delete Gmail messages.
  • No data is sold, shared with, or transferred to third parties, and none is used for advertising.
  • OAuth tokens are stored only in the owner's local secure storage (macOS Keychain).

Google API Services 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
